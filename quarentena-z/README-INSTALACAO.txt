APOCALIPSE — ZOMBIE TOWER DEFENSE
================================

COMO JOGAR NO WINDOWS
1. Extraia TODO o conteúdo do ZIP para uma pasta.
2. Abra a pasta zombie-tower-defense.
3. Dê dois cliques em INICIAR_JOGO.bat.
4. O jogo abrirá no navegador padrão.

Se o navegador bloquear algum recurso local, use INICIAR_COM_SERVIDOR.bat.
Essa segunda opção precisa do Python 3 instalado e inicia um servidor local.
Para encerrar o servidor, feche a janela de comando chamada "Apocalipse servidor".

LINUX / macOS
Execute iniciar_jogo.sh ou abra index.html em Firefox, Chrome ou Edge.

REQUISITOS
- Navegador atualizado com suporte a HTML5 Canvas e JavaScript.
- Não precisa de internet: os arquivos do jogo e as imagens estão incluídos.
- Extraia o ZIP antes de iniciar; não execute o HTML dentro do visualizador do ZIP.

SALVAMENTO
Recordes e preferências são guardados no armazenamento local do navegador.
Use o mesmo navegador e perfil para manter os dados. Limpar os dados do navegador
pode apagar esses registros.

SOLUÇÃO DE PROBLEMAS
- Tela sem imagens: confirme que a pasta assets está ao lado de index.html.
- Jogo não inicia: extraia novamente o ZIP e use outro navegador atualizado.
- O modo com servidor requer Python 3; a inicialização direta não requer Python.

Este projeto é uma aplicação web local, não um instalador .EXE nativo.
